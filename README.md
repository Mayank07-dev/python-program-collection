# Python Programs Collection

A small collection of beginner-friendly Python programs that practise loops, recursion, functions and data structures.

## Programs

| File | What it does |
|------|--------------|
| `factorial.py` | Calculates the factorial of a number using a loop and using recursion |
| `fibonacci.py` | Prints the first *n* Fibonacci numbers and finds the *n*th term |
| `structure_to_dict.py` | Converts tuples, lists, class objects, dataclasses and nested structures into dictionaries |

## Requirements
- Python 3.8 or higher (no external libraries needed)

## How to run
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/python-programs-collection.git
cd python-programs-collection
python factorial.py
python fibonacci.py
python structure_to_dict.py
```
